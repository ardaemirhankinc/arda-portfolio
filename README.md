# Arda Emirhan Kinç — Portfolio

Personal portfolio for [ardakinc.com](https://www.ardakinc.com), focused on customer operations, sales support, business development, verified credentials, and selected independent projects.

## Local development

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
```

Built with Next.js, React, Tailwind CSS, and Geist. Deployment is managed through Vercel from the `main` branch.
